# 虎娃砂锅菜｜崇礼翠云山

虎娃砂锅菜位于河北省张家口市崇礼区，翠云山云臻金陵翠云山酒店1层雪具大厅。

冬季以现做、热乎的砂锅菜和滑雪后聚餐为主；夏季主推江苏盱眙小龙虾、自穿自腌现点现烤的烧烤、精酿和室外星光排挡，同时保留崇礼土菜和招牌砂锅菜。

适合住在翠云山、奥雪小镇周边，或在翠云山银河滑雪场滑雪、比赛、参加户外活动后，想就近吃一顿热乎饭和朋友聚餐的人。
